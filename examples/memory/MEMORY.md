# MEMORY — Example Project Index

This is a working example of the memory directory structure used by the
Mira Fleet Architecture. Drop the `examples/memory/` directory into your
own project to start with the same shape.

## Index (hand-curated)
- [Example feedback memory](feedback_example.md) — what a behavioral rule looks like
- [Example project memory](project_example.md) — what active-work context looks like
- [Example reference memory](reference_example.md) — what an external-systems pointer looks like

## Notes
- Synthesizer (if present) appends below the divider, not into the index above.
- Rotate to `MEMORY.md.archive-YYYY-MM-DD` when the file exceeds the budget.
- Each memory file uses YAML frontmatter with `name`, `description`, and `type`.
- Keep the index to ≤150 lines. Bloat goes to a dated archive.
